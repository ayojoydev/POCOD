# GitHub Flow

1. Создай отдельную ветку для задачи.
2. Добавь новый файл или измени существующий.
3. Сохрани изменения коммитом и отправь ветку на GitHub.
4. Открой Pull Request в `main` и проверь список изменений.
5. После проверки выполни слияние и синхронизируй локальную `main`.

В этом упражнении новый файл добавлен в папке `lab2`, а корневой README дополнен описанием работы.
